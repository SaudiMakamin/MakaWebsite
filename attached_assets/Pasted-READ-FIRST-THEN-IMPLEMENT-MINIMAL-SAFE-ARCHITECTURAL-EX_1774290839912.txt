- User-facing pages must stay inside the Makamin app/domain
- Google Apps Script must become backend-only infrastructure
- No direct script.google.com URLs in the public UI

Implement only the minimal safe changes required.

1) Create internal Makamin pages for:
- shareholder submit
- shareholder track
- shareholder success confirmation

2) Public routes must remain under the current site routing pattern.

3) Build a backend integration layer in the existing server only if required:
- submit endpoint
- track endpoint
- upload endpoint if files are supported
These endpoints may call Google Apps Script / Google services internally, but that integration must not be exposed in the frontend.

4) Remove all direct public links to:
- script.google.com
- google script exec URLs
from the user-facing React pages.

5) After successful submission, show a Makamin-native success state:
- confirmation message
- reference number
- notice that an email was sent to the registered email address

6) Preserve architecture:
- do not migrate frameworks
- do not redesign routing
- do not touch unrelated files
- do not change deployment model
